# Правила
Проверь metadata, canonical, robots, sitemap, SSR/SSG HTML, alt, CLS, внутренние ссылки и структурированные данные. Длины title и description оценивай по смыслу и сниппету, не по строгим лимитам. Убедись, что проектная конфигурация Next.js и редиректы сохранены. Запускай доступные проверки сборки; указывай ограничения.
